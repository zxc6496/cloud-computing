# 赛博朋克记忆翻牌游戏 🎮

一个具有现代UI设计和丰富功能的网页记忆翻牌游戏，采用赛博朋克风格设计。

## ✨ 功能特色

### 🎯 核心功能
- **随机生成的卡牌组合
- **两种难度选择**：简单（4×4）和困难（6×6）
- **实时分数和计时
- **连击奖励系统
- **配对成功特效动画

### 🏆 进阶系统
- **排行榜系统**：支持记录玩家昵称
- **按分数排序**：显示金银铜牌排名
- **成就系统**：5个精心设计的成就
- **本地存储**：所有数据保存在浏览器本地

### 🎨 用户体验
- **加载动画**
- **新手引导
- **分享功能
- **音效开关**
- **响应式设计**：支持手机和电脑
- **个人简历页面**：可从游戏中跳转

### 🎭 视觉效果
- **赛博朋克风格设计
- **玻璃拟态效果
- **霓虹渐变色彩
- **流畅的卡牌翻转动画
- **成就解锁通知动画

## 🎮 游戏玩法

1. **开始游戏**：点击开始按钮开始
2. **翻开卡牌**：点击任意卡牌翻开
3. **寻找配对**：找出两张相同图案的卡牌
4. **完成游戏**：配对所有卡牌即可胜利
5. **挑战高分**：尽可能快，连击获得更高分数

## 🎯 成就系统

| 成就 | 说明 |
|------|------|
